# Homologação — linguagem do centro de atenção

Data: 2026-09-28

## DEFINIDO
- Datas exibidas em “Precisa de atenção” usam formato humano pt-BR, não data crua de backend.
- Motivos técnicos deixam de competir com a ação principal.
- Severidade é traduzida para linguagem simples: “Ação importante” ou “Vale conferir”.
- Título, valor e ação continuam sendo os elementos principais do card.
- Nenhuma regra financeira ou prioridade calculada pelo backend é alterada.

## DEFINIDO — resolução inline de Entrada
- Entrada pendente sinalizada em “Precisa de atenção” é resolvida dentro da própria Home.
- “Confirmar entrada” não navega para o menu Entradas.
- Se ocorreu como previsto, a confirmação atualiza caixa, recursos e atenção e mantém o usuário na Casa.
- Se ocorreu diferente, os campos completos são expandidos no mesmo contexto antes da confirmação.
- A resolução continua usando o comando canônico de recebimento; nenhuma nova renda é criada.
